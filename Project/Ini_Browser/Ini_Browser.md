# ini Browser
一个专为 INI 配置文件设计的编辑器，支持多标签页编辑、字典翻译、插件系统和深色模式。虽说“没屁用”，但折腾起来还挺上头。

[githublink]查看源码[/githublink](https://github.com/firefairyZz/ini_browser)[afdian]暂时支持不了[/afdian](https://ifdian.net/)

## 项目简介
ini Browser 是一个用 Python 编写的桌面工具，专门为那些喜欢把时间花在整理 `.ini` 文件上的朋友准备。它支持多标签页同时编辑、内置字典翻译功能（方便处理多语言配置）、可自由扩展的插件系统，以及护眼的深色模式。

项目结构清晰，用户数据独立存放，支持自定义插件和库，适合开发者、游戏玩家以及任何对配置文件有执念的人。

## 核心功能

[icon]file-text-o;Red;img-10px;bk-20px[/icon]{**多标签页编辑**
同时打开多个 INI 文件，轻松切换，无需在文件夹里翻来翻去。}

[icon]language;Red;img-10px;bk-20px[/icon]{**字典翻译**
内置翻译功能，一键将键值或注释翻译成目标语言，多语言配置不再是噩梦。}

[icon]puzzle-piece;Red;img-10px;bk-20px[/icon]{**插件系统**
支持用户自定义插件，想加什么功能就加什么功能，让工具真正符合你的工作流。}

[icon]moon-o;Red;img-10px;bk-20px[/icon]{**深色模式**
保护视力，夜间编码更舒适，深色主题一触即换。}
