# 不只是编辑器，更是创作者的“世界”工坊：揭秘 World Editor

## 引言：创作，从不再被工具束缚开始

对于小说家、游戏策划或知识库管理者而言，最痛苦的事莫过于灵感迸发时，却被繁杂的文件夹、格式不统一的文档和割裂的操作界面打断思路。我们需要的，是一个能将**项目管理、深度编辑、视觉美化**融为一体的“容器”。

今天要介绍的开源项目 **WorldEditor_WE_** ，正是这样一个为创作者而生的“世界构建编辑器”。它基于 Electron 构建，却丝毫没有 Electron 应用常见的笨重感，反而凭借极其细腻的功能矩阵，让人眼前一亮。目前它已迭代至 **v0.7.0**，不仅拥有媲美专业 IDE 的文件管理能力，还加入了令人惊艳的**节点图编辑器**和**PS 风格历史记录**。

## 核心双核驱动：富文本与 Markdown 的完美联姻

WorldEditor 最聪明的地方，是在创建项目时就允许用户选择 **富文本模式** 或 **纯 Markdown 模式**。

*   **在富文本模式下**，它基于 Quill 引擎，提供了文字颜色、背景色、四种对齐方式，甚至支持字体与字号的自定义。写小说或设定集时，视觉层级一目了然。
*   **在 Markdown 模式下**，它提供了一个**可折叠的实时预览面板**，让习惯纯文本写作的用户也能获得 WYSIWYG（所见即所得）的体验。
*   **导出无死角**：它支持将文档导出为 Markdown、HTML、PDF（甚至保留背景色），还支持将整个项目打包为 ZIP，方便备份与分发。

## 杀手级功能：像管理代码一样管理你的创意素材

如果说编辑是“内功”，那么 WorldEditor 的文件管理就是“硬核机甲”：

1.  **文件树与全功能标签系统**：左侧边栏支持宽度自由调节（140-500px），文件不仅支持彩色标签和缩略图，甚至连**文件夹**本身都可以添加标签！这意味着你可以用“#重要”、“#待审”来标记整个章节目录。
2.  **批量操作革命**：支持 `Ctrl+点击` 或 `Shift+点击` 多选文件，甚至可以 `Ctrl+A` 全选后**批量添加/删除标签**或**批量删除**。整理几百个碎片文档，只需几秒钟。
3.  **暴力搜索**：不仅支持文件名和标签搜索，还支持**文件内容全文搜索**，并兼容通配符与模糊查找。

## 极致的视觉体验：Windows 11 原生质感与 13 种主题

作为一个桌面应用，WorldEditor 在 UI 上倾注了极大的心血：

*   **无边框窗口与三态模式**：它设计了 OA（启程页）、目录独占、完整 TA（双区域编辑）三种模式，侧边栏有平滑过渡动画，交互极度跟手。
*   **背景材质系统（Win11 专享）**：原生支持 **云母 (Mica)**、**亚克力 (Acrylic)** 和 **标签式 (Tabbed)** 材质，甚至提供了内容区、遮罩、标题栏三层透明度滑块。这在 Electron 应用中极为罕见，质感直接拉满。
*   **13 种预设主题**：从 GitHub、Dracula、Monokai 到 Nord、Solarized，再加上自定义配色，无论是编码风还是写作风都能驾驭。

## v0.7.0 重磅更新：节点图与全局撤销，向专业工具看齐

最新版本带来了两个极具想象力的特性：

1.  **纯 SVG/CSS 节点图编辑器（NGEngine）**：它内置了 5 种节点类型、4 种连线样式和贝塞尔端口。这意味着 WorldEditor 不再局限于文本，它可以用来做**思维导图、剧情分支树、甚至是轻量级的可视化编程**界面。
2.  **PS 风格历史记录面板**：支持全局/局部撤销，历史记录面板可以像 Photoshop 那样拖拽悬浮，并带有窗口边界限制。误操作？回退几十步都不怕。

## 细节控的狂欢：那些令人舒适的小设计

*   **项目固定**：常用项目可以固定在启程页和侧边栏顶部，首次运行还会自动固定“使用教程”。
*   **命令面板**：按下 `Ctrl+P` 即可呼出类似 VSCode 的命令面板，快速搜索命令和设置。
*   **账户系统**：虽然是本地账户，但支持头像上传（2MB 限制）和首字母自动生成，并将账户信息同步至项目所有者字段，让单人创作也充满仪式感。
*   **国际化**：内置中、英、日、俄四国语言，海外用户也能无缝上手。

## 技术栈速览与快速上手

该项目结构清晰，主力代码位于 `JS/` 目录。

- **核心框架**：Electron
- **编辑器引擎**：Quill 1.3.6 + KaTeX（数学公式）
- **打包与压缩**：archiver / unzipper
- **样式管理**：纯 CSS 变量（实现了强大的动态主题切换）

**想要立即体验？只需三步：**

```bash
# 1. 进入项目目录
cd JS

# 2. 安装依赖
npm install

# 3. 启动开发模式
npm start
```

构建 Windows 安装包也非常简单：
```bash
npx electron-builder --win
```
产物会自动输出到 `WE-Release/` 文件夹。
